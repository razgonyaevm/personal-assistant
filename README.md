# Personal AI Assistant

Продвинутый персональный ИИ-ассистент с поддержкой автономного цикла агента (Agent Loop), нативного tool calling, гибридной долговременной памяти, изолированной песочницы Docker, интеграции с MCP (Model Context Protocol), календарями, GitHub и телеграм-ботом / единым системным демоном.

Проект спроектирован как отказоустойчивая модульная система с поддержкой трассировки через OpenTelemetry и Phoenix.

---

## 🏗 Архитектура и технологии

- **Язык**: Python 3.11+
- **Управление LLM**: **LiteLLM Proxy** (в Docker) с поддержкой роутинга, фоллбеков и подключения моделей Google Gemini (`gemini-3.5-flash`, `gemini-3.5-flash-lite`, эмбеддинги).
- **Долговременная память**: Гибридное хранилище на базе SQLite (текстовый поиск + векторное/эмбеддинг сопоставление).
- **Изолированная песочница**: Docker-контейнер (`sandbox`) с поддержкой безопасного выполнения команд в bash, PowerShell 7 и Python в изолированной рабочей директории `/workspace`.
- **Интеграция MCP (Model Context Protocol)**: Самодельный клиент (поддержка `stdio` и `HTTP` транспортов) с автоматической регистрацией внешних инструментов в общем реестре.
- **Наблюдаемость (Observability)**: OpenTelemetry SDK, экспорт OTLP-трейсов в **Arize Phoenix**, детальное JSON-логирование.
- **Интеграции и навыки (Skills)**:
  - Управление файловой системой (чтение, запись, иерархия каталогов, шаблоны `AGENTS.md` и `SKILL.md`).
  - Личный календарь и парсинг внешних календарей (`.ics`, расписания занятий).
  - Напоминания (разовые, интервальные, ежедневные с планировщиком).
  - Интернет-поиск (DuckDuckGo search) и полный набор инструментов для работы с **GitHub** (issues, PR, коммиты, чтение/создание файлов в ветках).
- **Интерфейсы взаимодействия**:
  - Интерактивный CLI (на базе `prompt-toolkit` и `rich`).
  - Фоновый демон (`daemon.py`) с очередью задач (`TaskQueue`) и полноценным Telegram-ботом (`telegram_bot.py`), объединённым с общей памятью, очередью и фоновыми напоминаниями.

## ⚙️ Установка и запуск

### 1. Предварительные требования
- Docker и Docker Compose
- Python 3.11+

### 2. Настройка окружения
Скопируйте файл `.env.example` в `.env` и заполните необходимые ключи (в частности, `GEMINI_API_KEY`, `GITHUB_TOKEN`, токен Telegram-бота и параметры LiteLLM/Postgres):

```bash
cp .env.example .env
```

### 3. Запуск инфраструктуры (LiteLLM Proxy, Phoenix, Sandbox)
Поднимите сервисы с помощью Docker Compose:

```bash
docker compose up -d
```

### 4. Установка зависимостей Python
Установите пакет в режиме разработки:

```bash
pip install -e .
```

### 5. Запуск ассистента

- **Интерактивный CLI**:
  ```bash
  python -m assistant.cli
  ```

- **Запуск фонового демона и Telegram-бота**:
  ```bash
  python -m assistant.daemon
  ```

## 🔍 Основные возможности и команды

- **Инструменты агента**: Ассистент динамически вызывает инструменты ФС, выполняет код в песочнице, ищет информацию в памяти, работает с GitHub и внешними API.
- **Интеграция с Telegram**: Подключенный Telegram-бот (`telegram_bot.py`) работает через единый системный daemon, используя общую память, очередь фоновых задач и автоматический планировщик напоминаний.
- **Трассировка**: Все вызовы LLM и агента автоматически трейсятся и доступны в локальном UI **Arize Phoenix** по адресу `http://localhost:6006`.
- **Память и заметки**: Важные факты сохраняются через `memory_save`, а отчёты и итоги встреч записываются в директорию `workspace/notes/` в соответствии с инструкциями `AGENTS.md`.
