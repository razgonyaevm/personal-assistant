# Инструкция для навыка pdf-analyzer

Когда пользователь присылает вопрос или задачу по PDF-файлу:
1. **Точечные вопросы** (например: «сколько страниц?», «кто автор?», «покажи оглавление»):
   - Вызывай ТОЛЬКО `pdf_info`.
   - Отвечай коротко и строго на вопрос (например: *«В документе 24 страницы.»*).
   - НЕ читай страницы через `read_pdf` и НЕ делай пересказ, если об этом не просили.
2. **Поиск конкретной информации / термина**:
   - Используй `search_pdf(path, query)`, найди целевую страницу и прочитай только её через `read_pdf`.
   - Ответь на вопрос со ссылкой на страницу.
3. **Общий анализ / выжимка**:
   - Только если пользователь прямо попросил «сделай выжимку», «перескажи суть» или «о чём файл».
