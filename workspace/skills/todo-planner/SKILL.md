# Инструкция для навыка todo-planner

1. **Добавление дел из текста или ГС:**
   - Если пользователь перечислил несколько дел — создай отдельную задачу `todo_add` для каждого.
   - Подбери подходящую категорию (`Учёба`, `Т-Академия`, `Проект`, `Личное`, `Покупки`) и приоритет (`high`, `medium`, `low`).
   - Если упомянут дедлайн («до пятницы», «завтра») — вычисли точную дату `YYYY-MM-DD` от текущей даты.

2. **Сбор задач из внешних источников:**
   - Если просят «собери мои дедлайны из почты и GitLab в To-Do» — проверь `email_list_messages` / `gitlab_list_merge_requests`, выдели актуальные действия и сначала предложи список (или сразу добавь по прямой просьбе).

3. **Просмотр и закрытие:**
   - При запросе «что у меня по задачам?» вызови `todo_list(status="open")` и покажи сгруппированно по приоритету/срочности.
   - Когда пользователь говорит «я сделал ...» — найди задачу через `todo_list` и переведи в `todo_update(todo_id=..., status="done")`.
