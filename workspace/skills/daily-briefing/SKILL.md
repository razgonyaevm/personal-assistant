# Инструкция для навыка daily-briefing

Когда пользователь просит сводку на сегодня/завтра, «что у меня по планам», «доброе утро» или «брифинг»:
1. Узнай текущее время через `get_current_time`.
2. Получи:
   - расписание из внешнего календаря (`calendar_external_events`);
   - события из личного календаря (`calendar_list_events`);
   - активные напоминания (`reminder_list`);
   - незавершённые/последние задачи (`list_tasks`).
3. Собери всё в единый хронологический список на день (выделяя возможные накладки по времени — например, если пара пересекается со встречей или тренировкой!).
