# Инструкция для навыка meeting-notes

Когда пользователь просит оформить итоги встречи или заметку:
1. Создай файл в `notes/<короткое_имя>.md`.
2. Используй структуру:
   - `# Тема`
   - `## Ключевые решения` (список)
   - `## Следующие шаги` (чекбоксы `- [ ] ...`)
3. Соблюдай требования из `AGENTS.md`.
