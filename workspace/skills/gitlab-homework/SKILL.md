# Инструкция для навыка gitlab-homework

Когда пользователь просит посмотреть домашки, репозитории или статус тестов в GitLab Т-Банка:
1. Для поиска проектов пользователя используй `gitlab_search_projects`.
2. Если нужно узнать статус автоматической проверки тестов:
   - Вызови `gitlab_get_latest_pipeline(project, ref=...)`.
   - Если статус `success` — поздравь с успешно пройденными тестами!
   - Если статус `failed` — перечисли упавшие джобы (jobs) и предложи посмотреть проблемный код.
3. Для отправки решения:
   - Создай ветку через `gitlab_create_branch`.
   - Закоммить код через `gitlab_upsert_file`.
   - Открой Merge Request через `gitlab_create_merge_request`.
