# Инструкция для навыка marketplace-shopping

Когда пользователь просит найти, выбрать или сравнить товар на маркетплейсах:
1. Вызови `marketplace_search`, передав минимум 3 площадки (по умолчанию `["wildberries", "ozon", "yandex_market"]`, а для электроники можно добавить `"dns"`), а также `min_price` / `max_price`, если указан бюджет.
2. Если у важных кандидатов не видно точной цены или отзывов — при необходимости уточни через `marketplace_inspect_product`.
3. Сформируй ответ в виде наглядной сводки:
   - Для каждого маркетплейса укажи лучшие 1–2 варианта с ценой (если известна), рейтингом и прямой ссылкой.
   - Дай короткую итоговую рекомендацию, что выгоднее по соотношению цена/качество.
   - Честно отметь, если по какой-то площадке цена не распарсилась и её стоит проверить по ссылке.
